# Северный Анклав · ЗАРЯ 9.0

Основа: GitHub `stasaleksandrov481-netizen/SevAnklav`, ветка `main`, коммит `d27fa2beecf8cf18de7182a44fb72649afc79565`.
Работа выполнена в отдельной ветке `visual/bunker-unified-v9`.

## Что изменилось

- Освещение первой локации: читаемый холодный фоновый свет, более широкое мягкое затухание локальных источников, менее плотные тени, свет на лестничном пролёте. Красные маяки меняют действительную мощность света и яркость рассеивателя синхронно. Красный не используется как общий фильтр.
- Стоимость теней ограничена настройкой качества: 2/4/5 локальных источников плюс фонарь. Убрана прежняя ситуация, когда все попавшие в окрестность камеры лампы включали PCF13 одновременно. Контуры стен и мебели продолжают определять тени и физические препятствия.
- Новые материалы медицинского, лабораторного и технического пола, стальные крышки массивных стен, кабельные магистрали, инженерные люки, маркировка секторов. Статическая детализация не перерисовывается заново каждый кадр.
- Новая капсула V–17 с вертикальным ложем, рамой, направляющими, креплениями и прозрачной сдвижной крышкой. Положение ложа согласовано с положением персонажа. Новый диагностический блок и шкафы с читаемой крышей, креплениями и вентиляцией. Один из лабораторных столов получил детальную рабочую поверхность с реальным назначением оборудования; используется только верхняя поверхность исходного атласа.
- Лестница полностью заменена: отдельные параллельные перфорированные ступени, торцы, боковые несущие элементы, крепления, верхняя и нижняя площадки, направление спуска. Камера строго сверху. Спуск проходит по непрерывной траектории с проверкой физических препятствий, движением ног и шагами; масштаб не меняется. Окончание сюжетного спуска записывается после прохождения, чтобы прерывание не оставляло ложный флаг завершения.
- Волков использует одни и те же суставы при выходе из капсулы, в спокойной стойке и при ходьбе. Верхние и нижние сегменты имеют постоянную длину. Изменяются их позиции и углы, а не масштаб текстур. Обновлён атлас одежды; ботинки отделены от сегментов голени и сохраняют направление стоп при сгибании коленей. Остальные персонажи получили фактуру одежды, швы и дополнительные следы травм; плавные повороты и анимация падения сохранены.
- HUD: тонкие открытые сенсорные элементы без тяжёлых растровых ободков, более компактные джойстики, док рюкзака/КПК/света/паузы, отдельная контекстная кнопка, компактные руки и быстрые слоты. Области действия и джойстика разведены. Сохранены оба независимых касания, двойные нажатия для бега/перезарядки и поворот без оружия.
- Текущая задача оформлена коротким блоком со сворачиванием. Мини-карта показывает только пройденный инерциальный след, без раскрытия здания.
- Инвентарь собран заново: анатомический обзор и руки слева, носимое снаряжение по центру, осмотр предмета справа. Пустая сетка из 24 одинаковых рамок больше не заполняет окно. Изображение и описание предмета появляются при выборе. На небольших экранах доступна прокрутка. Ячейки обновляются без закрытия окна; при расширении рюкзака создаются дополнительные ячейки.
- Новая анатомическая схема с кликабельными областями, показателями целости, кровотечением, переломами и лечением. Используется исходная логика `med_apply_zone`; медикаменты можно перетаскивать на соответствующие области. Если руки заняты, нажатие на медикамент всё равно выбирает его для лечения.
- Система левой/правой руки и двуручного оружия сохранена. Фонарь можно убрать в рюкзак; свет исходит из руки. Резервирование одного двуручного предмета не создаёт его копию.
- Проверка магазина полностью отделена от старого окна: короткое движение оружия, небольшая карточка в стиле HUD, приблизительная оценка магазина, запас патронов. Точные данные о магазине постоянно не раскрываются. Проверка отменяется при смене оружия/перезарядке; во время осмотра выстрел не выполняется. Для ножа и пустых рук проверка не запускается.
- Уведомления: отдельная очередь с медицинскими, предупредительными, системными и обычными акцентами. Опасная травма прерывает менее важное сообщение, непрочитанное сообщение возвращается в очередь. Дубли ограничены. Плавное появление и исчезновение, время чтения зависит от длины текста, управление не перекрывается.
- Инвентарь, обыск, локальные терминалы и пауза используют общий набор материалов интерфейса. В общем HUD добавлены только условные ветки для первой локации; поведение остальных кампаний сохраняется. В `main.gd` изменена только метка версии. Загрузочные экраны с картинкой и минимальной длительностью 3 секунды сохранены.
- В экспортных пресетах явно указан `runnable`, чтобы редактор Godot 4.5.1 не выдавал ошибку отсутствующего ключа.

## Проверка

Godot 4.5.1, Compatibility/OpenGL. `tests/v9_visual.tscn` проверяет выход из капсулы, постоянство масштаба сегментов в разных позах, фонарь, обе руки, двуручное оружие, проверку магазина, немедленное обновление быстрых слотов, лечение перетаскиванием, вкладки и закрытие инвентаря, очередь уведомлений, проходимость лестницы, сенсорные стики и освобождение касаний.

Итог автоматического прогона: 54 проверки успешно, 0 провалено.

Дополнительно строится сетка проходимости по реальным коллизиям и проверяется достижимость 14 сюжетных точек от медицинского блока при открытых гермодверях. Это проверка доступности маршрутов, а не автоматическое полное прохождение сюжета.

Интерфейс проверяется при размерах 1280×720, 1920×900 и 2160×1080. Рендеринг проверен снимками из работающего Godot под Xvfb/Mesa llvmpipe. Это программный OpenGL, поэтому его скорость нельзя считать показателем FPS на Android. На физическом телефоне и в Godot 4.7 сборка не проверялась.

Запуск проверки:

```sh
godot --headless --path . --audio-driver Dummy --max-fps 60 tests/v9_visual.tscn
```

Тест устанавливает метку `qa8`, при которой запись сохранений отключена.

## Ресурсы

Растровые материалы созданы встроенным imagegen; геометрия лестницы, капсулы, крышки и диагностического блока — редактируемые SVG, без перспективного наклона. В игру включены:

- `assets/bunker/v9/materials.png`: четыре плоских сектора материалов; медицинский эпоксидный пол, технический металл, лабораторный пол и стальная структурная крышка стены.
- `assets/bunker/v9/engineering.png`: атлас оборудования. В игре используется верхняя поверхность лабораторного стола через AtlasTexture; остальные ракурсы атласа не используются.
- `assets/bunker/v9/volkov_parts.png`: атлас шести изолированных частей, с сохранением размещения исходного атласа.
- `assets/ui/v9/anatomy.png`: прозрачная медицинская визуализация. Кликабельность и отображение травм реализованы кодом, а не встроенным в изображение текстом.

Основные спецификации генерации: строго плоские равномерно освещённые материалы научного комплекса; графитовые и холодные серо-синие поверхности; действующий объект после недавней аварии, без тотальной ржавчины; медицинская фигура с мягкими тканями, скелетом и прозрачным фоном; отдельные части персонажа без изменения их положения в атласе. Сгенерированные изображения не заменяют игровые кнопки и надписи.

## GitHub и применение

```sh

```

```sh

git switch visual/bunker-unified-v9
```

Bundle требует исходный коммит `d27fa2b`, который уже есть в этом репозитории. Архив изменённых файлов — дополнительный способ применения с сохранением каталогов. Перед использованием откройте проект в редакторе Godot и дождитесь импорта новых ресурсов.
