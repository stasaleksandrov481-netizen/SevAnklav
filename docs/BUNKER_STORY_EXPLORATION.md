# Исследование и сюжет бункера

Основа: main 2df8abe.

## Изменения

- В zsave сохраняется bunker_explored. Посещённые комнаты остаются тусклой геометрией полов и мебели с исходными текстурами; это статические объединённые меши без источников света и теней. Передние стены исследованных комнат открываются для обзора. Существо рисуется только в комнате игрока. Это комнатная видимость, не полная система поля зрения Project Zomboid.
- Проверки декоративных элементов прозрачности ограничены 20 Гц. Новые снимки обстановки объединены по материалам. FPS на Android не измерен; повышение частоты кадров не гарантировано.
- Добавлены надписи секторов Label3D с проверкой глубины, огнетушители с ручками/этикетками, баллоны и табуреты на круглых основаниях.
- 14 этапов основного маршрута: терминал → служебный доступ → оружие и КПК → видеозапись → журнал → предохранитель → питание → технический переход → карантин → архив → насос → привод → подача питания → выход.
- Тексты записей взяты из scripts/bunker_story.gd, сохранены отдельно в bunker_records.json. Архив КПК доступен через снаряжение. Название «Кривцы» в документах не используется.
- Новая игра запускает открытие стекла капсулы и подъём Волкова с переносом к краю; масштаб модели не меняется. Управление возвращается после анимации. Продолжение пропускает вступление.
- Получение оружия открывает его видимость, стрельбу по физическим лучам и расход патронов. Добавлена сенсорная кнопка огня. Целится в направлении корпуса; отдельный правый прицельный джойстик пока не перенесён.
- Добавлены простые противники, включая двух при шестисекундном включении шлюза. Это базовая боевая реализация; противники не сериализуются, полноценная система смерти/повторной загрузки и старое медицинское тело не перенесены.
- HUD стал компактнее; кнопки снаряжения/КПК/огня оформлены в общей палитре, добавлен прокручиваемый архив записей. Это доработка текущего HUD, не полная замена всех интерфейсов старой игры.

## Проверка и границы переноса

Godot 4.5.1: bunker_full_story — все 14 взаимодействий, записи, оружие, задержка шлюза, выход и память комнат; bunker_intro — открытие, возврат управления, отсутствие масштабирования; bunker_lighting_smoke — освещение/коллизии/прозрачность. Графический запуск медблока, коридора и лаборатории без ошибок скриптов и ресурсов.

Тест сюжетного маршрута перемещает персонажа между точками и проверяет события; это не ручное прохождение боя. Для старого шестишагового story_interaction_smoke следует использовать новый bunker_full_story.

Сюжет адаптирован к существующему одноуровневому 3D-бункеру. Настоящий отдельный нижний этаж с лестницей, все дополнительные расследования старой локации, её медицинская система и полный набор постановочных анимаций пока не перенесены. Не считать эту версию полным переносом всех механик старой 2D-локации.
