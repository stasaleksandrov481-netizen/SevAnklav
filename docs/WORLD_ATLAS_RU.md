# Северный Анклав: карта и редактор

Откройте C:\MyDocuments\SevAnklav\project.godot в Godot 4.7.2. «Новая игра» начинает сюжет Волкова с пролога, затем открывает подземный объект «Заря». «Продолжить» загружает сохранённый слой и положение. В бункере E выполняет действие, Tab открывает вещи, M показывает карту, WASD двигает персонажа, Shift ускоряет его. Выход из бункера переводит Волкова на поверхность.

## Большая карта

Сетка содержит 320 × 240 участков по 64 × 64 м: 20,48 × 15,36 км. Во время игры загружаются ближайшие девять участков. Город, военная база, фермы, деревни, промышленная и карантинная зоны, леса, озёра и трассы генерируются при посещении. Это основа для ручной доводки: здания и предметы пока упрощены.

## Редактирование в Godot

1. В правом доке «Анклав 3D» нажмите «Открыть атлас региона»; он лежит в res://iso/atlas/world_atlas.tscn.
2. В EditableRoads меняйте точки Path2D для дорог; в EditableZones вершины Polygon2D для районов, леса и воды; в Markers перемещайте подписи. Ctrl+S. Генератор читает эти пути и зоны при запуске.
3. Для правки места в 3D щёлкните по маленькой карте в доке. Затем нажмите «Открыть / создать выбранный участок». Редактор сохранит текущий сгенерированный участок как res://iso/sectors/sector_X_Z.tscn.
4. Выделите дом, дорогу или предмет в дереве сцены, правьте в Инспекторе, сохраните Ctrl+S. Этот файл при загрузке заменит процедурный участок. Атлас не переписывает уже сохранённые участки автоматически.

Готовые редактируемые участки: центр Северограда (160,105) и соседние кварталы, военная база (250,30), ферма (42,155), деревня (35,115), лес (95,150), карантинная зона (270,75). Бункер: res://iso/buildings/bunker_start.tscn. Камень вокруг него: res://iso/sectors/sector_55_45.tscn.

Для своей модели положите .glb или .gltf в res://assets/models/, дождитесь импорта и назначьте её предмету через поле Model. Растровое изображение в assets/world/world_concept_reference.jpg служит ориентиром планировки.

## Текущие ограничения

Масштаб и потоковая загрузка реализованы, но детали зданий, анимации и предметы ещё требуют работы для уровня Project Zomboid. Старые 2D ресурсы пока остаются: исходные сюжетные сцены и скрипты на них ссылаются.
