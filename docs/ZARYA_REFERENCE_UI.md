# Интерфейс «Заря»: референс и производительность

HUD переработан по предоставленному изображению с указанными пользователем изменениями: питание и вода сверху по центру, здоровье в виде силуэта с травмированными областями, рюкзак и КПК сверху. Нижняя панель содержит две руки, лечение, быстрые слоты и утилиты. Проверка магазина и перезарядка остаются разными действиями; неизвестное количество патронов не превращено в точный счётчик.

Общие панели, предметные иконки, выделение и типографика применены к рюкзаку, двухколоночному обыску, КПК и лечению. Снаряжение, карманы и содержимое рюкзака разделены. Иконки пистолета и фонаря используют существующий растровый атлас; остальные расходники получили отдельные SVG-ресурсы. КПК имеет список записей и область чтения. Содержимое контейнеров и предметы используют прежнее состояние, без сброса сохранений.

При открытии окна игровые кнопки скрываются и блокируются полноэкранной подложкой. Независимые указатели двух джойстиков сбрасываются, исключая застрявшее движение/стрельбу при закрытии. Перерисовка нового окна однократно запрашивается после замены предыдущего: устраняет пропадание рамки и кнопки закрытия в Compatibility.

## Оптимизация без снижения графических настроек

- Источники света индексируются по комнатам вместо полного вложенного перебора.
- Параметры света, теней и видимости записываются в рендерер только при изменении.
- Проверки перекрытия стен переиспользуют результат при неизменных позиции персонажа и ориентации камеры; плавное завершение перехода продолжается 0,3 секунды.
- Невидимые скелеты не получают ненужные записи поз; симуляция противников остаётся активной.
- Иконки кешируются; мини-карта перерисовывается при перемещении/исследовании, сегментированные показатели — при изменении отображаемого значения.
- Разрешения текстур, геометрия, дальность/качество света и теней не снижались.

В одинаковом headless-тесте Godot 4.5.1, 19 исследованных помещений, 1000 обновлений: CPU-время одного обновления видимости/освещения в покое 526,950 → 113,486 мкс; при перемещении 524,789 → 440,765 мкс. Это измерение конкретной подсистемы, не FPS игры. GPU и Android FPS этим тестом не измеряются. Воспроизведение: `--headless --path . --script tests/zarya_perf.gd`.

## Проверка

- 91 проверка уровня: двери, сюжет, сохранения, предметы, обе руки, боеприпасы, пробуждение — без ошибок.
- 18 проверок нового UI: отсутствие полосы здоровья, оба показателя, независимый мультитач, сброс джойстиков, drag-and-drop и немедленное обновление руки, обыск без повторной выдачи предметов, КПК/медицина и размещение на логических viewport для 1280×720, 2340×1080, 1024×768 — без ошибок.
- Графический запуск Compatibility / Mesa llvmpipe: HUD, инвентарь, обыск, КПК и медицина осмотрены по реальным скриншотам в `docs/previews/reference-ui/`.
- На скриншотах тестовый уже полученный набор предметов; старт игры по-прежнему без оружия. Изображения не являются концептами/генерацией.
- Физическое Android-устройство недоступно: аппаратный FPS и удобство реального пальцевого управления требуют проверки на телефоне.

Работа касается интерфейса и вычислительной оптимизации существующего уровня. Окружение на скриншотах остаётся текущим игровым окружением; оно не подменено фоновой картинкой референса.
