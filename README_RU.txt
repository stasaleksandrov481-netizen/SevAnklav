СЕВЕРНЫЙ АНКЛАВ — ГРАФИЧЕСКОЕ ОБНОВЛЕНИЕ БУНКЕРА V11

В этом архиве только новые и изменённые файлы. Они уже разложены
по правильным путям относительно корня проекта Godot.

Изменено:
  assets/bunker/v11/furniture_atlas.svg — 16 новых объёмных 2D-спрайтов мебели
  scripts/bunker/v10/furnishing.gd — подключает новый атлас вместо старого
  scripts/bunker/v11/visual_dressing.gd — потертости, люки, кабели, следы аварии

УСТАНОВКА
1. Сделать резервную копию проекта или новую ветку в GitHub.
2. Распаковать архив с сохранением структуры папок в корень проекта.
3. Разрешить замену scripts/bunker/v10/furnishing.gd.
4. Открыть проект в Godot, дождаться импорта SVG, запустить локацию «Бункер».

Не заменены: персонажи, основные стены, двери, миссии, интерфейс, коллизии.
Старые спрайты сохранены в assets/bunker/v10 для отката.

Важно: через подключённый GitHub разрешено чтение, но запись изменений
отклонена GitHub (HTTP 403). Поэтому готовое обновление здесь — ZIP, а не
коммит в основной ветке. Выполнение в редакторе Godot и тест на Android
в этой среде не производились.
